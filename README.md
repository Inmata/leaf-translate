# Leaf · 叶译

一个简洁的 Windows 划词与剪贴板翻译工具。复制或选中文字，按快捷键看译文；遇到不懂的词，再展开解释或继续追问。

由你自己的智谱、千问或 DeepSeek API 驱动。原文语言自动识别，目标语言、模型和接口地址可以调整。

![首版浮窗，使用演示文本](docs/images/popup.png)

## 开始使用

适用于 Windows 10/11，需要 .NET Framework 4.8。首版为便携程序，不需要安装，也不需要 Node.js、Python 或 .NET SDK 才能运行。

1. 下载并解压构建产物，双击 `Leaf.exe`。首次启动打开设置。
2. 选择 API 服务，填写自己的密钥，点击「测试连接」，再「保存设置」。连接测试会发送一条很短的请求，可能计费。
3. 默认是剪贴板模式：先复制文字，再按 **Ctrl+Alt+T**。
4. 点击原文单词展开词卡；点击「追问」才出现输入框。Enter 发送，Shift+Enter 换行。

托盘右键可以切换取词模式、打开设置或历史记录，以及退出。收起浮窗会保留当前会话。开机启动默认关闭。

没有 API 密钥时，可以运行 `Leaf.exe --demo` 查看带有明确标记的演示内容；演示不发送网络请求，也不写入真实历史。

## 已实现

- 可配置全局快捷键；剪贴板模式只在按快捷键时读取，不持续上传复制内容。
- 选中模式优先系统选区接口，失败后尝试模拟复制；取词失败明确提示，不翻译旧剪贴板。
- 浮窗唤起不抢焦点；点击外部收起，置顶后保持显示；追问不会自动置顶。
- 流式译文、语境词卡、原形与词性、有效译文片段高亮、同一窗口追问。
- 场景与学习偏好通过选项设置，自定义项和组合预设可复用。游戏字段只在游戏场景出现。
- 本地历史默认保留最近 200 条，可搜索、继续追问、删除、清空或关闭保存。回看不调用 API。
- 相同在途请求合并，新文本取消旧请求，迟到结果不能覆盖新会话；缓存包含语境、语言、模型和接口。
- Windows 凭据管理器保存密钥；单实例、托盘、可选开机启动、指定显示器及窗口位置记忆。

默认模型为 `glm-4.7-flash`、`qwen-flash`、`deepseek-chat`。模型名可改，实际可用性、价格与额度以服务商账号为准。

## 数据与调用

设置和历史保存在 `%LOCALAPPDATA%\LeafTranslate`。密钥单独保存在 Windows 凭据管理器，不写入设置或历史 JSON。应用没有自建中转服务器。

主动翻译时，原文和场景信息发往设置中的接口；查词额外携带原句、译文和学习选项；追问携带相关材料及最多最近 12 条对话。打开历史不联网。从旧历史继续查词或追问，使用当前保存的接口和模型，同时保留那条记录的学习语境。

关闭保存历史会清空已有记录。历史有数量和内容长度上限，超出时移除最旧记录。取消请求会停止本地等待，但不能保证供应商不计费。

## 本地构建

在 Windows PowerShell 中，项目目录下执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1
```

产物是 `bin\Leaf.exe` 和 `bin\Leaf.exe.config`。构建使用 Windows 的 .NET Framework 编译器，无第三方包、无需恢复依赖。

```powershell
# 运行核心、HTTP 链路、会话并发和窗口检查
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/test.ps1

# 构建便携 ZIP
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/package.ps1
```

GitHub Actions 会在 Windows 上构建、检查，并生成可下载的便携包。

已登录 Inmata 的 GitHub CLI 可以发布首版：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/publish.ps1 -WithRelease
```

脚本检查账号和公开仓库，只复制列出的源码目录，使用独立临时 Git 检出，不改动工作区已有 Git 元数据，不强制推送。`-CheckOnly` 可以先查看发布文件清单。`-WithRelease` 同时上传已构建且校验通过的便携包。

## 首版验证与范围

本地已通过 **69 项核心与会话断言、16 项窗口检查**，包括本机真实 HTTP 流式联调、UTF-8 分片、错误分类、取消、历史限额、缓存失效、查词与追问并发，以及嵌入 XAML 渲染。截图使用示例内容。

真实供应商请求需要用户自己的密钥，本次未进行真实账号联调。跨软件取词、焦点、多屏 DPI 和托盘交互仍需在实际桌面中体验；自动检查不能替代这些兼容性验证。尚未测量实际托盘驻留内存。

首版不包含 OCR、截图识别、独占全屏游戏适配或自动寻找屏幕空白。连写语言可以选中原文片段、右键「解释选中片段」；本地词语划分并非所有语言的专业分词器。

LLM 解释可能出错，提示词要求区分词源与记忆联想，并承认不确定；没有接入额外的判断模型。
