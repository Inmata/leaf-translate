# 叶译首版使用说明

**简体中文** · [English](USAGE.en.md) · [项目首页](../README.md) · [下载软件](https://github.com/Inmata/leaf-translate/releases/latest)

## 配置 API

首次启动或托盘右键「设置」进入配置页。选择智谱、千问或 DeepSeek，填写模型与密钥。密钥输入框不会显示已有密钥；留空表示继续使用已保存的密钥。修改接口地址必须重新填写密钥。展开「接口地址」可以使用兼容的 HTTPS 服务；本机调试允许 localhost HTTP。

「测试连接」使用当前未保存的配置发送短请求；成功后仍需点击「保存设置」。智谱与千问按各自兼容接口关闭推理内容，首版只展示文字结果。模型支持及价格以供应商文档和账号权限为准。

## 日常使用

默认先复制，再按 Ctrl+Alt+T。来源提示写明「来自剪贴板」。若想直接选中后按快捷键，在托盘或设置中关闭剪贴板模式。

浮窗出现时保留原软件的焦点。点单词会显示词卡，并在找到有效对应片段时高亮译文。可以通过「返回整句」切换追问对象。非空格分词的文字，或跨词短语，可以在原文中拖选后右键解释。

点「追问」显示输入框，Enter 发送、Shift+Enter 换行。问题围绕原句或当前词语；不自动置顶。新文本开启新会话，旧会话可以从历史找回。

点浮窗外部或右上角收起按钮会隐藏窗口。点击置顶后，外部点击保持显示，收起按钮依然有效。浮窗可以拖动、调整大小；设置中可以指定显示器，适合副屏使用。

快捷键占用、没有文字、网络断开、超时、密钥错误、额度不足、限流和返回格式异常都有对应提示。失败时不会无限重试，可以手动重试或修改配置。输入原文上限为 6000 个 UTF-16 字符；过长时请分段。

## 学习偏好

阅读场景依次提供通用、书籍、影视、技术文档、游戏及自定义。场景没有语言限定。目标语言默认为中文，可直接填写其他语言。

对应场景才显示补充信息。例如，选择书籍显示书名，选择游戏显示游戏名称和文字类型；切换场景会清空上一场景的补充文字。

原形与词形、近义词比较、构词与词根、常见搭配、短例句都可以勾选。没有合适选项时，展开「添加自己的学习偏好」，填写名称和简短要求，添加后作为普通选项使用。自定义项旁的 × 可以删除该项。偏好预设保存当前场景、目标语言和学习选项；最后保存设置才生效。

## 历史与退出

成功翻译后自动记录。同一段原文的译文、词卡和追问保存在一条记录中；复制而没有翻译的内容不会记录。默认保留最近 200 条，在设置中可调整为 20–1000 条，另有存储内容长度上限。

历史可搜索原文或译文，双击或点击「查看与继续追问」恢复。恢复本身不调用 API。旧历史继续查词、追问使用当前服务配置，保留历史原句及学习语境。

删除记录会同时移除其缓存。关闭保存历史会清空已有历史，并停止新增。数据位于 `%LOCALAPPDATA%\LeafTranslate`；若数据损坏，程序会尽量保留 `.corrupt-时间` 备份。密钥位于 Windows 凭据管理器的 `LeafTranslate/服务标识`。

关闭/收起浮窗继续驻留；真正结束程序请用托盘「退出」。开机启动默认关闭。启用后请把程序放在固定位置，移动程序后重新关闭并开启开机启动。

## 常见情况

- 找不到托盘图标：查看任务栏隐藏图标区域。
- 无法读到选区：切回剪贴板模式，先手动复制。管理员权限软件或自绘文字可能不能直接取词。
- 热键冲突：在设置中改为其他 Ctrl、Alt 或 Win 组合。
- 不支持的模型：检查服务商控制台，把设置中的模型名改成你账号可用的模型。
- 重复启动：只保留一个实例，后启动的实例尝试唤起浮窗。
- Windows 提示应用未签名：首版没有代码签名；源码和构建脚本在公开仓库中可检查。本项目不会要求关闭系统防护。

首版没有 OCR 与独占全屏适配。应用是 Windows 原生 WPF 程序，当前没有 macOS/Linux 版本。
