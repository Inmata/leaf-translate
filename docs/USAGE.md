# Leaf 使用说明

**简体中文** · [English](USAGE.en.md) · [项目首页](https://github.com/Inmata/leaf-translate) · [下载软件](https://github.com/Inmata/leaf-translate/releases/latest)

## 配置 API

首次启动或托盘右键「设置」进入配置页。先填写 API Key，再选择 API 服务。OpenAI、智谱、千问和 DeepSeek 提供官方地址预设；其他服务选择「自定义兼容服务」，展开「接口地址」填写基础 URL。也可先填自定义地址，再填密钥。

确定接口后，停止输入便自动获取模型，并显示加载与结果。选择支持文字对话的型号，也可以直接填写官方文档中的模型 ID；「刷新模型」可重试。密钥不用于猜测厂商，也不会被逐家试探。目录返回模型归属信息时显示，没有则不猜测；部分接口不提供列表，仍可手动输入。保存后记住服务与接口，下次更换密钥自动刷新。

模型目录与账号权限、额度是两回事，选好后请测试连接。密钥输入框不会显示已有密钥；下方提示「已保存密钥」时，留空表示继续使用。修改接口地址必须重新填写密钥。展开「接口地址」可以使用兼容的 HTTPS 服务；本机调试允许 localhost HTTP。

「测试连接」使用当前未保存的配置发送短请求；成功后仍需点击「保存设置」。只展示正文，思考内容不进入译文。模型支持及价格以供应商文档和账号权限为准。获取模型会认证访问当前服务的目录，不发送原文或对话。

模型下方的「高级选项」默认收起。思考模式可选自动适配、开启、关闭；建议保留自动。GLM-5.3 / Flash 必须思考，「关闭」不可选，默认轻量，可改为增强或深度。未知 GLM 沿用服务默认思考模式。思考请求最多等待 120 秒。

OpenAI 和自定义兼容接口沿用模型默认思考设置，不发送其他供应商的专用参数；思考模式控件会停用，输出上限仍可调整。当前仅支持 Chat Completions 接口，不支持只提供 Responses、原生 Anthropic Messages 等其他协议的服务。

输出 token 上限留空时自动适配，GLM-5.3 系列默认 8192。自定义范围 256–32768；包含思考与正文，过小可能截断回答。上限不等于实际用量，费用由服务商按实际使用计费。

## 日常使用

新用户默认选中文字后按 Ctrl+Alt+T，剪贴板模式关闭。若习惯先复制，在托盘或设置中开启剪贴板模式，再按 Ctrl+C 和翻译快捷键；来源提示写明「来自剪贴板」。只在按快捷键时读剪贴板，不会上传每次复制。升级保留已保存的模式。

浮窗出现时保留原软件的焦点。点单词会显示词卡，并在找到有效对应片段时高亮译文。可以通过「返回整句」切换追问对象。非空格分词的文字，或跨词短语，可以在原文中拖选后右键解释。

点「追问」显示输入框，Enter 发送、Shift+Enter 换行。问题围绕原句或当前词语；不自动置顶。新文本开启新会话，旧会话可以从历史找回。

点浮窗外部或右上角收起按钮会隐藏窗口。点击置顶后，外部点击保持显示，收起按钮依然有效。浮窗可见时有任务栏图标，收起后继续托盘驻留。

首次浮窗固定在主屏右侧。拖动和调整大小后自动记住，下次唤起或重启继续使用该位置与尺寸；重试时不移动。直接拖到副屏即可，无需设置显示器。屏幕拔出或工作区域变小时，窗口会恢复到可用屏幕范围内。

设置快捷键时，点击输入框后直接按组合键，不需要输入名称。须包含 Ctrl、Alt 或 Win 与另一个按键；Esc 取消，保存后生效。录入期间当前全局热键暂时释放，结束后恢复。支持 Alt+Space；Leaf会拦截 Windows 的窗口菜单快捷键，长按只触发一次，退出后恢复。若其他快捷键工具也使用它，请在其中一处改为不同组合。

缩小浮窗会适度缩小正文、行距和留白，保持可读下限；按钮尺寸不变，长内容可滚动。放大窗口不额外放大字号。

快捷键占用、没有文字、网络断开、超时、密钥错误、额度不足、限流和返回格式异常都有对应提示。失败时不会无限重试，可以手动重试或修改配置。输入原文上限为 6000 个 UTF-16 字符；过长时请分段。

## 学习偏好

阅读场景依次提供通用、书籍、影视、技术文档、游戏及自定义。场景没有语言限定。目标语言默认为中文，可直接填写其他语言。

对应场景才显示补充信息。例如，选择书籍显示书名，选择游戏显示游戏名称和文字类型；切换场景会清空上一场景的补充文字。

原形与词形、近义词比较、构词与词根、常见搭配、短例句都可以勾选。没有合适选项时，展开「添加自己的学习偏好」，填写名称和简短要求，添加后作为普通选项使用。自定义项旁的 × 可以删除该项。偏好预设保存当前场景、目标语言和学习选项；最后保存设置才生效。

## 历史与退出

成功翻译后自动记录。同一段原文的译文、词卡和追问保存在一条记录中；复制而没有翻译的内容不会记录。默认保留最近 200 条，在设置中可调整为 20–1000 条，另有存储内容长度上限。

历史可搜索原文或译文，双击或点击「查看与继续追问」恢复。恢复本身不调用 API。旧历史继续查词、追问使用当前服务配置，保留历史原句及学习语境。

删除记录会同时移除其缓存。关闭保存历史会清空已有历史，并停止新增。数据位于 `%LOCALAPPDATA%\LeafTranslate`；若数据损坏，程序会尽量保留 `.corrupt-时间` 备份。密钥位于 Windows 凭据管理器的 `LeafTranslate/服务标识`。

关闭/收起浮窗继续驻留；真正结束程序请用托盘「退出」。开机启动默认关闭。启用后请把程序放在固定位置，移动程序后重新关闭并开启开机启动。

## 诊断日志

托盘右键「打开日志」会打开 `%LOCALAPPDATA%\LeafTranslate\logs`。当前文件为 `leaf.log`，旧文件为 `leaf.1.log` 至 `leaf.4.log`，每个最多 1 MiB，自动轮换。

每行是一条 JSON 记录，包含时间、版本、请求 ID、服务与模型、接口主机、耗时、HTTP 状态、服务错误码/相关参数、异常类型和应用方法位置。不记录密钥、原文、译文、学习语境、追问或完整服务错误正文；不会自动上传。记录 `started` 后没有结束记录时，可能是程序被强制结束。

反馈问题时说明复现步骤和出错时间，可附对应日志。提交前自行检查，不要附私人历史或密钥。日志目录不可写时，翻译仍可使用。

## 常见情况

- 找不到托盘图标：查看任务栏隐藏图标区域。
- 无法读到选区：切回剪贴板模式，先手动复制。管理员权限软件或自绘文字可能不能直接取词。
- 热键冲突：在设置中改为其他 Ctrl、Alt 或 Win 组合。
- 不支持的模型：点击「刷新模型」更新目录，或按服务商文档手动填写账号支持的模型 ID，然后测试连接。
- 重复启动：只保留一个实例，后启动的实例尝试唤起浮窗。
- Windows 提示应用未签名：首版没有代码签名；源码和构建脚本在公开仓库中可检查。本项目不会要求关闭系统防护。

首版没有 OCR 与独占全屏适配。应用是 Windows 原生 WPF 程序，当前没有 macOS/Linux 版本。
