# 叶译首版需求

整理自已确认的产品讨论，是以后聊天接续开发的依据。目标为 Windows 10/11 桌面应用。

## 取词与窗口

- 全局快捷键可配置，默认 Ctrl+Alt+T。
- 剪贴板模式默认开启：按快捷键时读取文字，不持续翻译每次复制。
- 选中模式优先 UI Automation，后尝试模拟复制。失败必须提示，不用旧剪贴板。
- 来源提示明确。唤起不抢焦点，点词后交互，点追问后才显示并聚焦输入框。
- 未置顶时窗口外点击收起，点击仍传给原软件；置顶时保持。追问不自动置顶。
- 手动收起总有效；保留会话和草稿。托盘退出结束程序、解除快捷键和钩子。
- 支持拖动、按显示器记忆位置、指定副屏、不同 DPI、屏幕拔出后回到可用屏幕。
- 顶栏仅来源、置顶、收起。场景选择进入设置。
- 首版不含 OCR、截图翻译、独占全屏适配、自动寻找空白。

## 翻译与学习

- 智谱、千问、DeepSeek 兼容接口；模型名/接口地址可调整，不保证供应商额度或费用。
- 输入语言自动识别；目标语言默认中文。场景不带语言限定。
- 先显示简洁译文；词语兼顾释义、词性和原形。
- 原文常驻、单词可点击、浅色块高亮。只对有效目标片段做译文高亮，不强行逐词对应。
- 词卡携带原句、选词位置、译文与语境；按偏好讲词形、近义词、构词、搭配和例句。
- 连写语言允许选中原文片段，右键解释；不承诺本地正则准确分词所有语言。
- 不凭形似认定同源；分清词源与记忆联想；缺少依据时保留不确定性。
- 同浮窗追问整句或当前词。新文本开启新会话；同内容可恢复；历史可继续追问。
- 旧历史保留学习语境，新查词和追问使用当前已保存的接口及模型，词卡缓存区分接口和模型。

## 设置

- 场景预设：通用、书籍、影视、技术文档、游戏。游戏最后；另有自定义。
- 只显示对应字段：游戏名称/文字类型、书名、影视名、技术领域或自定义说明。
- 场景、风格、学习选项组合提示词。用户可添加“名称 + 希望怎样讲解”的学习项。
- 密钥仅存 Windows Credential Manager。修改接口地址需重新填密钥。
- 开机启动可选，默认关闭。

## 请求与历史

- 合并相同在途请求；模型、接口、原文、目标语言、语境和偏好一致才复用。
- 新请求取消旧请求；版本号阻止迟到响应覆盖。取消不保证供应商免除费用。
- 不无限重试；网络、超时、密钥、额度、限流、模型与格式错误明确提示。
- 主译文流式；词卡校验 JSON；追问按需调用；限制输入和送出的会话上下文。
- 成功翻译自动保存；原文、词卡、追问归一条。复制但未翻译的不保存。
- 托盘历史支持原文/译文搜索、回看、继续追问、删除、清空、关闭保存。
- 默认最近 200 条，数量可设；回看不请求 API；删除同步清理相应内存缓存。
- 设置/历史本地存储；关闭保存时清理已有历史。
- 单实例、托盘驻留、退出释放资源；资源占用需实测，不将规划预算当成测量值。

## 实现与验证

采用 .NET Framework 4.8 原生 WPF。Windows 自带运行环境，本地构建不需下载第三方包。

验证 SSE、供应商请求、错误分类、词卡校验、上下文缓存键、历史限额/删除/关闭、取消、热键和 XAML 渲染。无用户 Key 时只用本地兼容接口联调，不能宣称真实供应商已测试。取词和显示器兼容性需在用户桌面实际体验。
