# Leaf 产品需求

整理自已确认的产品讨论，是以后聊天接续开发的依据。目标为 Windows 10/11 桌面应用。

## 取词与窗口

- 全局快捷键可配置，默认 Ctrl+Alt+T。
- 新设置的剪贴板模式默认关闭；保留旧用户已保存的选择。开启后按快捷键读取文字，不持续翻译每次复制。
- 快捷键通过按键录入，Esc 取消；录入时暂时释放当前全局热键，结束或关闭设置后恢复。
- 选中模式优先 UI Automation，后尝试模拟复制。失败必须提示，不用旧剪贴板。
- 来源提示明确。默认唤起不抢焦点；可开启「快捷键唤起后直接输入」，取词完成后聚焦原文并选中全文。点追问后显示并聚焦问题输入框。
- 原文区域可编辑，Enter 提交、Shift+Enter 换行，或点击编辑状态下的「翻译 ↵」。手动提交建立新会话，清除旧词卡和追问；默认原文显示可点击词语，编辑按钮/直接键入可进入编辑。
- 译文使用可选中的只读文档，Ctrl+C/右键复制选区，Ctrl+A 全选。剪贴板写入与取词在独立 STA 线程处理，有限等待与错误反馈；不显示单独的复制译文按钮。
- 未置顶时窗口外点击收起，点击仍传给原软件；置顶时保持。追问不自动置顶。
- 手动收起总有效；保留会话和草稿。托盘退出结束程序、解除快捷键和钩子。
- 首次浮窗位于主屏右侧。记住最后拖动的位置及调整后的尺寸，重新唤起和重启后恢复；重试或更新可见浮窗不移动窗口。
- 不提供显示位置或显示器选择。可自行拖到任意屏幕；不同 DPI 下保持逻辑尺寸，屏幕拔出或分辨率变化时把窗口恢复到可用区域。
- 浮窗可见时显示任务栏入口，托盘与程序窗口使用统一图标；收起后继续托盘驻留。
- 缩小浮窗时适度缩小正文、行距和留白，缩放下限 84%；学习正文至少 12 DIP，按钮保持原尺寸。放大不放大字号，长内容滚动显示。
- 支持 Alt+Space，专门拦截此组合避免唤起 Windows 窗口菜单；长按只触发一次，退出解除钩子。
- 顶栏仅来源、设置、置顶、收起。追问位于左下角；展开后收起入口并允许折叠输入。场景选择进入设置。
- 视觉采用「清晰纸面」：白色背景、深色正文、清楚的次级文字和中性控件，靠留白与细分隔线组织内容。避免整片灰绿或给每段内容套卡片。主要按钮使用深色；绿色仅用于状态和焦点。追问为左下角轻量图标文字入口，浮窗、设置和历史沿用同一套控件样式。
- 即时显示浮窗，再异步取词；桌面/任务栏无选区时直接准备手动输入。系统最小化或隐藏后重新恢复 HWND，不依赖 WPF IsVisible，不默认激活。
- 首版不含 OCR、截图翻译、独占全屏适配、自动寻找空白。

## 翻译与学习

- 名称统一为 Leaf，设置/密钥/历史数据沿用原路径，不因更名重置。
- 预设 OpenAI、智谱、千问、DeepSeek，另有自定义兼容服务。使用 Chat Completions 协议，模型 ID/接口地址可调整，不保证供应商额度、费用或其他原生协议。
- 设置顺序为服务、API Key、模型。切换服务展示对应密钥状态和记住的模型；未指定接口时不发送密钥，不按密钥格式猜测厂商，不逐家试探。确定接口并填入密钥后自动获取模型。
- 模型目录有 owned_by/provider 信息时显示接口提供的模型归属；没有时不猜。目录可能包含非文字模型，提示选择支持文字对话的型号。
- 新设置不预填固定模型。用密钥请求当前接口的模型列表，用户明确选择；不支持列表或获取失败时保留手动填写。
- 填入密钥后停顿 600 ms 自动获取模型，立即显示准备/加载/成功/失败状态。切换服务、修改密钥或地址、关闭设置取消旧请求；不让迟到列表覆盖当前服务。
- 模型高级选项默认折叠：思考模式自动/开启/关闭、输出 token 上限；GLM-5.3 系列必须思考，禁用关闭选项，默认轻量并可选增强/深度。未知 GLM 不强制禁用思考。
- GLM-5.3 系列自动输出上限 8192，思考请求最长等待 120 秒；只展示正文，不显示 reasoning_content。自定义上限 256–32768，包含思考用量。
- OpenAI 用 max_completion_tokens，不发送固定 temperature 或其他供应商的思考参数；OpenAI 与自定义接口沿用模型默认思考设置。GPT-5+ / o 系列与未知自定义模型自动输出上限 8192、等待 120 秒，兼容接口保留最小通用参数。
- DeepSeek/兼容服务使用 models 接口，千问官方服务使用百炼文本模型目录并分页；不向其他域名转发密钥，不自动选用昂贵模型。
- 输入语言自动识别；目标语言默认中文。场景不带语言限定。
- 先显示简洁译文；词语兼顾释义、词性和原形。
- 原文常驻、单词可点击、浅色块高亮。只对有效目标片段做译文高亮，不强行逐词对应。
- 词卡携带原句、选词位置、译文与语境；按偏好讲词形、近义词、构词、搭配和例句。
- 连写语言允许选中原文片段，右键解释；不承诺本地正则准确分词所有语言。
- 不凭形似认定同源；分清词源与记忆联想；缺少依据时保留不确定性。
- 同浮窗追问整句或当前词。新文本开启新会话；同内容可恢复；历史可继续追问。
- 旧历史保留学习语境，新查词和追问使用当前已保存的接口及模型，词卡缓存区分接口和模型。

## 设置

- 场景预设：通用、书籍、影视、技术文档、游戏。游戏最后；另有自定义。
- 只显示对应字段：游戏名称/文字类型、书名、影视名、技术领域或自定义说明。
- 各场景分别保存补充名称，切换及重新打开设置后恢复；旧版本的当前名称迁移到对应场景。
- 场景、风格、学习选项组合提示词。用户可添加“名称 + 希望怎样讲解”的学习项。
- 密钥仅存 Windows Credential Manager。修改接口地址需重新填密钥。
- 已配置服务的模型切换自动应用；新的密钥、接口和高级参数通过「应用服务配置」提交，验证并保存当前服务，应用后保持窗口打开。已有密钥不回填，框内用独立的深色实心密码圆点占位，框下显示已保存状态和替换提示；聚焦或输入时隐藏占位，留空继续使用。占位内容不能成为请求密钥，也不表示真实密钥长度。
- 场景、语言、学习选项、预设和使用习惯停顿 400 ms 后自动保存并反馈，关闭时冲刷待应用变更；不依赖 API 配置完整。应用这些偏好不打断当前请求，下一次翻译使用新偏好。服务模型停顿 500 ms 自动应用，仅限已配置地址和密钥；不提交未完成的服务配置。
- 开机启动可选，默认关闭。

## 请求与历史

- 合并相同在途请求；模型、接口、原文、目标语言、语境和偏好一致才复用。
- 新请求取消旧请求；版本号阻止迟到响应覆盖。取消不保证供应商免除费用。
- 不无限重试；网络、超时、密钥、额度、限流、模型与格式错误明确提示。
- 主译文流式；词卡校验 JSON；追问按需调用；限制输入和送出的会话上下文。
- 成功翻译自动保存；原文、词卡、追问归一条。复制但未翻译的不保存。
- 托盘历史支持原文/译文搜索、回看、继续追问、删除、清空、关闭保存。
- 默认最近 200 条，数量可设；回看不请求 API；删除同步清理相应内存缓存。
- 设置/历史本地存储；关闭保存时清理已有历史。
- 单实例、托盘驻留、退出释放资源；资源占用需实测，不将规划预算当成测量值。
- 本地诊断日志通过托盘打开，记录版本/系统、请求 ID、服务/模型、接口主机、耗时、状态码、错误码/参数和应用异常位置。不记录密钥、请求/响应正文、学习语境或对话；无自动上传。
- 日志每文件上限 1 MiB，最多当前文件和四份备份；写入失败不影响应用。错误界面保留经过密钥脱敏的服务消息，日志仅保留结构化元数据。

## 实现与验证

采用 .NET Framework 4.8 原生 WPF。Windows 自带运行环境，本地构建不需下载第三方包。

验证 SSE、供应商请求、错误分类、词卡校验、上下文缓存键、历史限额/删除/关闭、取消、热键和 XAML 渲染。无用户 Key 时只用本地兼容接口联调，不能宣称真实供应商已测试。取词和显示器兼容性需在用户桌面实际体验。
