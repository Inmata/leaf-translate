## 一、产品边界

- [ ] P01：浮窗集中于原文、纯译文、展开学习。
- [ ] P02：追问的入口、输入区、问答列表、请求与关联状态完整移除，不改名保留。
- [ ] P03：原文选区快捷键跳转子会话、返回原会话的整个设计移除。
- [ ] P04：正常原文编辑提交、普通历史查看保留。

## 二、学习入口与分类

- [ ] L01：全部入口统一叫展开学习；句子、段落也能使用。
- [ ] L02：整份输入是单词 / 短语，翻译后自动请求并展开学习。
- [ ] L03：整份输入是句子 / 段落，先只翻译，点击展开才请求，不后台预生成。
- [ ] L04：单击或双击词自动学习完整词，同一次双击不重复请求。
- [ ] L05：中文、日语点击位置通过学习请求定位完整词，不只解释一个字。
- [ ] L06：拖选允许任意连续范围，不能按词数强行划分类别。
- [ ] L07：拖动、松手、键盘改选区和程序高亮时，主模型与 Jev 都零请求。
- [ ] L08：拖选后点展开才分类，支持单词、短语、句子、段落。
- [ ] L09：学习标题附近轻量显示类型和当前对象。
- [ ] L10：词语、句子、段落三组学习偏好独立保存；一次只显示一组设置。
- [ ] L11：已有词语学习格式与用户自定义要求保留。
- [ ] L12：句子讲整句意思 / 结构；段落讲主要意思 / 句间关系，避免强套词卡格式。
- [ ] L13：学习真正增量显示标题与正文，不能等完整 JSON 或只显示等待中。

## 三、翻译、语种与交换

- [ ] T01：主译文保持纯翻译，不混入教学，保留合理段落和换行。
- [ ] T02：只设置目标语言，不要求用户填原文语言。
- [ ] T03：常见目标语言下拉，自定义罕见语言；自定义输入不常驻拥挤。
- [ ] T04：交换仅作用当前会话，不改全局默认目标语言。
- [ ] T05：来回交换复用两份完成文本，不重复翻译。
- [ ] T06：隐藏再恢复保留方向；新内容 / 正式提交编辑使用默认目标语言。
- [ ] T07：交换按钮调整到可用尺寸，与既有视觉统一。

## 四、Jev 与缺失判断

- [ ] J01：Jev 可选、默认关闭；不开启仍有全部功能。
- [ ] J02：关闭时，首次翻译附带语种 / 类型；明确学习请求附带分类和讲解。
- [ ] J03：开启时，首次判断与翻译并行；明确学习时 Jev 分类、主模型讲解。
- [ ] J04：缓存命中时，主模型和 Jev 都不调用。
- [ ] J05：判断缺项只补问缺项一次，不重做译文 / 讲解，不因缺项永久丢失展开入口。
- [ ] J06：其他 / 混合 / 未知语种有出口；Jev 不可用时使用主模型判断。
- [ ] J07：设置中只增加轻量开关及按需 Key 输入，保持简洁。
- [ ] J08：支持导入现有 TYPESAFE_API_KEY；密钥只存 Credential Manager。
- [ ] J09：README 写清好处、额外 Key、费用和关闭时行为；不承诺必然更准 / 更快。
- [ ] J10：已有八样例证据不冒充四类正式验收；交付时补齐对应验证。

## 五、复用与取消

- [ ] C01：同会话、同条件 A → B → C → A，复用完成 A。
- [ ] C02：同对象正在生成，共用在途请求。
- [ ] C03：未完成 A 切到 B，停止 A；返回未完成 A 时重新请求。
- [ ] C04：取消 / 半份内容不能算完整缓存，已完成结果不被取消抹掉。
- [ ] C05：按位置和语境区分同形词，如银行和河岸的 bank。
- [ ] C06：完整词定位也缓存，点研究的研 / 究均可找到同范围结果。
- [ ] C07：原文版本、方向 / 目标语言、服务 / 模型、相关场景 / 偏好和规则版本参与复用条件。
- [ ] C08：先本地查缓存，再决定调用模型，不为查缓存先分类。
- [ ] C09：每会话 32 份完整结果作为建议默认，采用最近使用淘汰，不混同历史条数。
