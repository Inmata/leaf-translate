# 设置页

## 目标

翻译服务配置与阅读偏好在同一浮窗内的设置页完成。切换翻译页与设置页时保留翻译页和当前会话；历史保持独立入口。

## 原因

服务、密钥、模型、语言、字体等设置分散出错会直接影响翻译请求和隐私：密钥写错位置会泄露，迟到的模型列表会覆盖当前服务，关闭设置时丢失待保存偏好会让用户以为已生效。这些行为跨多个会话开发，需要一份比 PRODUCT.md 更贴近代码的验收清单。

## 验收

- 密钥只存 Windows Credential Manager，按服务与规范化接口地址绑定；不进入设置文件、历史、日志或源码。成功提交新地址后才清理旧地址目标，失败不迁移。
- 已有密钥不回填，只显示占位与已保存状态；占位内容不能成为请求密钥，留空继续使用已保存密钥。
- 填入密钥后停顿 600 ms 自动获取模型；切换服务、修改密钥或地址、关闭设置会取消旧请求，迟到列表不覆盖当前服务；不支持列表或获取失败时保留手动填写。
- 场景、语言、学习选项、预设和使用习惯停顿 400 ms 后自动保存并反馈，关闭设置时冲刷待应用变更；不依赖 API 配置完整，不打断当前请求，下一次翻译使用新偏好。
- 已配置服务的模型切换停顿 500 ms 自动应用；新的密钥、接口和高级参数通过「应用服务配置」提交并验证，应用后窗口保持打开；不提交未完成的服务配置。
- 目标语言为下拉选择，选「自定义」才显示输入框，留空不保存；旧版本自由文本语言按自定义保留；设置中没有源语言控件。
- 字体默认内置思源黑体 SC，可选已安装文本字体；浮窗、设置页、历史窗口和已建立的阅读文档立即更新；所选字体不可用时回退内置字体并轻量提示。
- 设置内容底部显示当前版本号，位于最后一组之后、固定状态行之前。
- 各场景分别保存补充名称，切换及重新打开设置后恢复。

## 边界

- 行为以 docs/PRODUCT.md「设置」一节为准；本 spec 不改变该文档的需求。
- docs/plans/v0.6.0 中对设置与字体的调整是计划，不是已实现行为；实施后再更新本 spec。
- 视觉样式、布局像素和控件细节不在本 spec 内，由人工检查。
