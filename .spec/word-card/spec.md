# 词卡

## 目标

用户点选原文中的词语，浮窗内显示带语境的词卡：释义简短、词形从当前用法解释，按勾选的偏好补充近义词、构词与词源、搭配和例句。

## 原因

词卡内容来自模型输出，容易出现不可靠的词源、被静默截断的字段或脱离原句的泛泛解释。这个功能跨多个会话迭代，且 0.6.0 计划还会调整词卡渲染，需要固定哪些行为不能退化。

## 验收

- 词卡携带原句、选词位置、译文与语境，按用户勾选的偏好讲解；自定义学习项沿用用户给出的名称与要求。
- 不凭形似认定同源；区分词源与记忆联想；缺少可靠依据时保留不确定性，不硬拆构词。
- 例句明确标注为新造；搭配优先放回原句。
- 词卡校验 JSON；解析失败时显示「词卡暂未完成。」类提示，不显示残缺内容。
- 词卡受限字段按文本元素边界截断，保留代理对与组合字符；原文 6000 字符上限只提示，不静默截短。
- 自动单词路径对中文、日文等连写文字及含句末标点的输入保守地走句段翻译；只有明确的拉丁词形（含撇号、连字符、组合音标）按单词处理。显式选中片段仍可右键解释。
- 只对有效目标片段做译文高亮，不强行逐词对应。
- 旧历史保留学习语境；新查词使用当前已保存的接口及模型，词卡缓存区分接口和模型。

## 边界

- 行为以 docs/PRODUCT.md「翻译与学习」一节为准；本 spec 不改变该文档的需求。
- 追问不在本 spec 内：docs/plans/v0.6.0 已决定删除追问，实施前 PRODUCT.md 中的追问条目仍是现行行为。
- 词卡流式渲染、句子与段落学习模式属于 0.6.0 计划，尚未实现；实施后再更新本 spec。
- 模型输出质量与供应商兼容性无法由自动检查证明，需人工体验。
